# Ultracodeeditor
CodeEditor is a responsive, web-based live coding environment that allows users to write and preview HTML, CSS, and JavaScript in real-time. It offers a simple and intuitive interface, making it perfect for learning, prototyping, and testing front-end code instantly within the browser.

 Features
* Live HTML, CSS, and JavaScript editing

* Real-time output preview using <iframe>

* Minimal UI with FontAwesome icons

* Quick access to Docs, Help, and Tools via navigation

* Responsive design layout (left panel: code, right panel: output)


#Technologies Used
HTML5
CSS3
JavaScript 

#To use locally:
Clone or download the repository
Open index.html in your browser
Start writing HTML/CSS/JS and see live preview instantly
